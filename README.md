# 🏥 Medical Billing Software

A full-stack Medical Billing Management System built with Flask and SQLAlchemy to streamline patient billing, medicine management, invoice generation, and healthcare administration workflows.

## 📌 Project Overview

Medical clinics and pharmacies often rely on manual billing processes, which can lead to errors, inefficiency, and poor record management.

This project provides a centralized solution to:

- Manage patients and medicines
- Generate medical bills and invoices
- Track billing records
- Store data securely in a relational database
- Improve workflow efficiency in healthcare environments

---

## 🚀 Features

### Patient Management
- Add new patients
- View patient records
- Update patient information
- Search patient details

### Medicine Management
- Add medicines
- Update stock information
- Track medicine pricing
- Manage medicine inventory

### Billing System
- Generate invoices
- Calculate total bill automatically
- Maintain billing history
- Store transaction records

### Database Management
- Persistent storage using SQLAlchemy ORM
- Relational database design
- Data validation and integrity

### User Interface
- Flask-based web application
- Responsive forms
- Clean navigation structure

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/lockish/Medical-Billing-software.git
cd Medical-Billing-software
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
